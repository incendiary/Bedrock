Infrastructure-as-code template with Bedrock's security posture built in:
three-layer secret scanning, Terraform formatting and validation, advisory
static analysis, Dependabot, and branch protection.

---

## Layout

| Path | Purpose |
|------|---------|
| `versions.tf` | Terraform and provider version pins |
| `variables.tf` | Input variables, including owner, region, and ttl |
| `main.tf` | Provider configuration and common tags |
| `outputs.tf` | Outputs, including the common tag set |
| `terraform.tfvars.example` | Copy to `terraform.tfvars` (gitignored) and fill in |
| `modules/` | Reusable modules |

---

## Setup

```bash
terraform init
terraform fmt -check -recursive
terraform validate
```

Copy `terraform.tfvars.example` to `terraform.tfvars` and set the required
variables. `terraform.tfvars`, state files, `.terraform/`, and AMI identifiers
are gitignored and must never be committed.

## Plan and apply

```bash
terraform plan -out tfplan
# Apply only against an account you are authorised to use.
terraform apply tfplan
```

## Development

```bash
pre-commit install
pre-commit run --all-files
```

Checkov runs in advisory mode: it reports findings but does not fail the build,
because infrastructure built from this template may host deliberately vulnerable
services by design.
